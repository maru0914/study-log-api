# 0001 実行する Node を 24 にそろえる

- 日付: 2026-10-11
- 状態: 決定

## 背景

型の定義（@types/node）は Node 24 用なのに、実行は Node 22.20.0 だった。
そのため、24 にしか無い API を使っても型の検査は通り、22 で動かすと落ちる。
Nest CLI の依存も 22.20.0 を対象外にしている。

## 比べた案

1. 実行は 22 のまま、@types/node を 22 に下げる
2. 実行を 24 に上げ、.nvmrc で固定する

## 決めたこと

2 にした。
型（@types/node 24）と手元の実行（Node 22）のバージョンがずれていて、24 にしか無い API を使っても tsc は通り、実行すると落ちる状態だったため。デプロイ先のバージョンは、デプロイするときに 24 を選ぶ（例: Docker の node:24、Lambda の nodejs24.x）

## 結果

- node -v が v24、.nvmrc に 24
- 24 で tsc のエラー0・e2e 6件通過
- better-sqlite3 は Node 22 向けにビルドされていたため、24 に上げたあと npm rebuild が要った（NODE_MODULE_VERSION 127 → 137）
